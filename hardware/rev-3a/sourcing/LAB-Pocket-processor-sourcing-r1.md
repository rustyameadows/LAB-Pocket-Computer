# LAB Pocket processor and camera sourcing · revision 1

November 27, 2026 · USD · Rev 3A baseline e3854ad

**For an unchanged Rev 3A, pursue the exact 32 MB P4 through Wireless-Tag as a turnkey manufacturer. For a new high-performance board with both processor and optics listed at JLC, start with Rockchip RK3568. For a conventional microcontroller and an actual second assembly supplier, start with STM32H743IIT6 at NextPCB.** These recommendations address different costs: preserving engineering, buying compute headroom, and securing repeatable procurement. No assembler has accepted the complete design or committed to delivery. No order, file upload, vendor message or quote request has been made.

## 1. Keep the current processor, layout and software target

Wireless-Tag appears in Espressif's distributor directory, sells a module using the 32 MB v3.2 P4, and offers OEM manufacturing. ## 2. Five processor and camera combinations with both items in JLC's public catalog stock

All five entries below use the lens-equipped LCKFB-GC2093-200W-MIPI-AF-V1, C52160596. JLC returned **847 at $7.1945**. The module uses a 2 MP 1920 × 1080 sensor and a focus motor. A second stocked GC2093 assembly, C42388918, had **244 at $5.5557** and uses a fixed-focus lens. JLC lists the autofocus unit for assembly. Verify flex-connector orientation, cable geometry, position behind the display, lens clearance, and whether the assembler will fit or supply the optical module with the boards. The module manufacturer's documentation includes drawings and autofocus instructions. [JLC autofocus module](https://jlcpcb.com/partdetail/LCSCboards-GC2093_200W/C52160596) · [JLC fixed-focus module](https://jlcpcb.com/partdetail/C42388918) · [Module drawings and software](https://wiki.lckfb.com/zh-hans/lushan-pi-k230/image-recog/use-sensor.html)

For the first two, use the Rev 3A panel's 18 RGB data lines and published timings, dedicated 480 Mbit/s-capable USB port, separate codec/mic interfaces and the actual lens assembly in the feasibility schematic. Assign SD, radio, RP2350 and control lines before floorplanning. The redesign also needs a boot device, a DDR and power design with a supported initialization sequence, and a board software package. Measure active, idle and suspend current on a representative design and confirm simultaneous preview, stereo audio, mic capture and SD writes before committing to a production layout. The Jauch pack and existing regulators impose real limits on continuous load.

Allwinner's V853 development-board schematic and pin definitions offer a candidate arrangement with the RGB panel on port D, digital microphone clock and data on port H and the stereo codec on port E. Its example camera software uses a different sensor. For RK3576, the clock and compute resources come with a larger power and memory subsystem. The more expensive design cannot be assumed to run longer or render this 320 × 320 interface more smoothly without measurements. ## 4. Why several apparently easy substitutions fell down

- **ESP32-S31NRV16.** JLC showed 280 chips. Native HS USB, RGB and I²S are appropriate. The Rev 3A host already uses all 55 P4 GPIO numbers. DVP replaces dedicated CSI lanes with roughly a dozen general signals. A feasible S31 budget uses integrated radio, I²S0 for the four PDM mics, I²S1 for the stereo codec, and another PCA9555 for panel setup/reset, card detect and other slow controls. A second PCA9555PWR had 6,002 at JLC. No stocked complete conventional DVP camera matching that plan was identified in JLC's image-sensor catalog. An assembler could procure the Seeed flex externally as part of its order. Individual boot straps, all signal assignments and the complete board still need verification. [JLC processor](https://jlcpcb.com/partdetail/C55601453) · [Espressif pin map](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s31/schematic-checklist.html) · [Audio capabilities](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32s31/include/soc/soc_caps.h)
- **RK3566 and RV1106G3.** Both have GC2093 software evidence and substantial JLC stock. The detailed RK3566 guide does not substantiate the full RGB666 pinout advertised in the short brief. On RV1106G3, the vendor pin table puts the native LCD and external audio I²S on the same pads. A microphone converter by itself does not free those pins. RK3568 and RV1126B have stronger evidence for the complete LAB display/audio combination. [RK3566 camera](https://wiki.t-firefly.com/en/ROC-RK3566-PC/driver_camera.html) · [RK3566 hardware guide](https://dl.xkwy2018.com/downloads/RK3568/RK356X/Hardware/Rockchip_RK3566_Hardware_Design_Guide_V1.1_EN.pdf) · [RV1106 pin assignments](https://github.com/LuckfoxTECH/luckfox-pico/blob/main/sysdrv/source/kernel/arch/arm/boot/dts/rv1106-pinctrl.dtsi)
- **NXP RT1170 A-series stock and Canaan K230D.** NXP identifies a MIPI RAW data limitation on RT1170. A matching CSI connector is insufficient proof for the existing raw IMX219 or the GC2093. The K230D has a particularly strong verified GC2093 software path and JLC showed 361 chips. Its documented display output uses MIPI DSI; our existing panel needs parallel RGB. That would add a bridge or panel change. [NXP engineering response](https://community.nxp.com/t5/i-MX-RT-Crossover-MCUs/RT1170-Using-MIPI-CSI-with-grayscale-or-raw-image-sensors/m-p/1270310) · [K230 LCD interface](https://www.kendryte.com/k230/en/main/01_software/board/mpp/K230_LCD_Adaptation_Guide.html)

## 5. From component availability to a board that ships

For the existing board, supply the dedicated procurement ZIP to an assembler that can own the bare-chip purchase. A meaningful positive reply names the traceable U1 lot and available quantity, confirms the other short lines and stackup, states the prototype minimum, and gives a board dispatch date. Obtain separate line items for the battery harness, display, camera and other hand-installed items in the same order if desired.

For a new host, freeze one pin map against the actual panel, camera, stereo codec, four microphones, two SD sockets, secondary RP2350 and USB role. Use the sensor reference design as the first software bring-up and test the full display/audio/camera/SD workload together. Add the new power, memory and boot circuits and rerun electrical, mechanical, placement and routing checks. The actual build lead time starts after design release and materials acceptance. The current repository provides CAD and assembly outputs; no tracked shipping firmware image was identified. No redesign in this report has fabricated or validated LAB hardware.
