# Layout reference

The supplied image sets the visual direction for the exposed-board instrument. Use a square color-wheel screen between two seven-segment touch rails, a four-by-four tactile grid, an upper rear optical cluster, edge lighting and a lower central rear-mounted USB-C port. Leave the four board corners clear of through-holes.

The image's dimension labels are concept values. Rev A uses the measured panel body and the flat battery's cycled envelope. See [the mechanical basis](../fit.md) for the selected parts and current outline.
